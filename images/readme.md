# Add your media files to this folder

## Image files go here
- `ernest-portrait.jpg` — Your main portrait photo (used on the About section)
- `og-image.jpg` — A 1200×630px image for sharing on social media / WhatsApp (use a good portrait or project shot)
- `menada-hero.jpg` — Best Menada campaign image
- `menada-photo-1.jpg`, `menada-photo-2.jpg`, `menada-photo-3.jpg` — Product/lifestyle photos
- `menada-promo.mp4` — The Menada promotional video (optional, can use YouTube embed instead)
- `dab-hero.jpg` — DAB podcast cover or studio image
- `aphro-hero.jpg` — APHRO brand visual or video still
- `blood-remembers-flyer.jpg` — Official production flyer (you have this already)
- `blood-remembers-hero.jpg` — Stage photo or flyer as banner
- `brabo-leone-production.jpg` — Production photo (request from NITE at nite.nl)
- `thumb-1.jpg`, `thumb-2.jpg`, `thumb-3.jpg`, `thumb-4.jpg` — TikTok video thumbnails (screenshots from your TikTok)
- `favicon.ico` — Your favicon (can use a simple "K" icon)

## To add images to the site:
1. Copy your image file into this folder
2. Open the relevant HTML file
3. Find the comment that says `<!-- Replace with: <img src="images/YOUR-FILE.jpg"> -->`
4. Follow the instructions in the comment

## Video files (optional):
You can host videos here if they are small (under 50MB).
For larger videos, use YouTube embeds — instructions are in each page's HTML comments.

## Tips:
- Keep image files under 2MB each (compress at tinypng.com for free)
- Use JPG for photos, PNG for logos/graphics
- Name files with lowercase letters and hyphens only (no spaces)
